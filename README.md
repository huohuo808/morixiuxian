## 核心设定速览

- **世界**：天裂 100 年后，灵气从天空裂缝倾泻，但带来"蚀"污染。修炼 = 把自己改造成能装更多蚀的容器，越强越不像人。
- **金手指**：主角体内有断口碎片，能吞蚀化力，代价是身体局部异化。
- **主线**：护妹 → 荒原求生 → 中枢博弈 → 断口抉择。
- **终极问题**：为了活下去，你愿意变成什么？变成那样之后，你还是你吗？
